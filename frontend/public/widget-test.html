Website Chat — Widget Test

Missing channel key. Open this page from Omnichannel → your Website Chat channel → Open test page, or add ?key=YOUR_PUBLIC_KEY to the URL.

Use the chat button in the bottom-right corner. This page loads the same embed script as your channel detail screen.

  1. Click the purple chat button.
  2. Enter your name and email, then click Start chat.
  3. Read the greeting and send a message (e.g. Hello, I need help).
  4. Wait up to 30 seconds for the AI reply (widget refreshes every 4s).
  5. Click Talk to Human to request a live agent.
  6. Check Omnichannel → Unified inbox for name, email, and handoff status.

Channel key:

Each organization and channel has its own public key. Copy it from the channel detail page in the admin app, or use the Open test page link there.
